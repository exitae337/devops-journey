
# **Для чего же нужен git?**

Представим себе ситуацию когда два человека работают над одним и тем же файлом `config.yaml`. Первый и второй вносят свои изсенения на своих компьютерах. После всех измененний воникает вопрос - какая версия данного файла явдяется **актуальной**? Если просто пересылать файл через мессенджер или заменить его на сервере, одна из версий просто будет потеряна. А вдруг в случае ошибки надо будет **откатиться**? 

Для разрешения этой проблемы (и не только) появились системы контроля версий (VSC) - программа, которая сохраняет историю изменений файлов. Git - стандарт индустрии который необходим для упрощения процесса разработки.

### Git позволяет

1. Отслеживать изменения в файлах
2. Сохранять версии файлов. Всегда можно посмотреть историю изменений и при необходимости откатиться на рабочую версию. Для отслеживания возникшей ошибки - самое-то.
3. Сохранять ветки для параллельной работы
4. Объединять изменения разных пазработчиков и при необходимости откатываться к люой версии проекта

*В итоге у нас есть уверенность в том, наш проект находится под полным контролем. Захотели реализовать новую фичу? Создали для этого ветку! Понравились изменения? Слили с главной! Если же изменения не нужны и планы поменялись, то просто удаляем ветку.*

Для совместной работы используются специальные сервисы - например **GitHub**.
